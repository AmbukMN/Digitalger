# ⚠️ Анхаарах — хүний шийдвэр шаардлагатай зүйлс

Автомат сканаар илэрсэн боловч **код засаж шийдэх боломжгүй** асуудлууд.
Эзэн эргэж ирээд шийднэ.

## 🔴 1. Имэйл ОГТ илгээгдэхгүй байна

**Төлөв:** production дээр идэвхтэй асуудал
**Илэрсэн:** 2026-08-09

### Юу болсон бэ

`AWS_ACCESS_KEY_ID` / `AWS_SECRET_ACCESS_KEY` нь
`/opt/BestTV/backend/.env.production`-д **огт байхгүй**.

Backend startup лог:

```text
[EmailService] AWS түлхүүр байхгүй — имэйл илгээхгүй (лог хийнэ)
```

### Нөлөө

Дараах бүх имэйл **явахгүй**:

| Загвар | Хэрэглэгч юуг мэдрэх |
| --- | --- |
| `payment` | Багц худалдаж авсан ч **баримт ирэхгүй** |
| `rental` | Түрээслэсэн ч баталгаа ирэхгүй |
| `password-reset` | **Нууц үгээ сэргээж ЧАДАХГҮЙ** — холбоос хэзээ ч ирэхгүй |
| `verify` | Имэйл баталгаажуулалт дуусахгүй |
| `welcome` | Шинэ хэрэглэгч угтах захидал авахгүй |

`password-reset` нь хамгийн ноцтой — нууц үгээ мартсан хэрэглэгч
**бүртгэлдээ дахин орох арга байхгүй** болно.

### Хэзээ эвдэрсэн

`EmailLog`-ийн сүүлийн `sent` бичлэг — **08-08 07:53** (`password-reset`).
Түүнээс хойш имэйл илгээх оролдлого гараагүй бололтой (лог хоосон).
Түлхүүр тэр орчимд алга болсон байх магадлалтай.

### Хэрхэн засах

```bash
ssh root@62.238.47.2
nano /opt/BestTV/backend/.env.production
# нэмэх:
#   AWS_ACCESS_KEY_ID=<түлхүүр>
#   AWS_SECRET_ACCESS_KEY=<нууц түлхүүр>
#   AWS_REGION=eu-north-1        # анхдагч ижил
#   MAIL_FROM=noreply@besttv.us  # анхдагч ижил

cd /opt/BestTV/docker
docker compose -f docker-compose.prod.yml -p besttv up -d --force-recreate --no-deps backend

# Баталгаажуулах — энэ мөр гарах ЁСТОЙ:
docker logs besttv-backend 2>&1 | grep "AWS SES бэлэн"
```

> ⚠️ SES-ийн оронд Resend ашиглах бол `email.service.ts` дотор
> провайдер солих код бичих шаардлагатай (одоо зөвхөн SES).

### Одоо нэмсэн хамгаалалт

Админ хянах самбар дээр **🔴 «Имэйл илгээх тохиргоо дутуу»** гэсэн
критик сэрэмжлүүлэг гарна. Өмнө нь зөвхөн startup лог дээр нэг мөр
гардаг тул админ хэзээ ч мэдэхгүй байв.

## ⚠️ 2. «Шилдэг кино» багц — контент дутуу

**Төлөв:** хөрвүүлэлт дуусахад автоматаар шийдэгдэнэ

9,900₮-өөр зарагдаж байгаа багцад 5 кино холбоотой боловч бэлэн нь
байхгүй. Хоёр нь (`Тэмцээн`, `Өвдөлт тэсвэрлэгч`) хөрвүүлэлтэд байна.

Захиалга **0** тул хэн ч мөнгө алдаагүй.

Хөрвүүлэлт дуусахад сэрэмжлүүлэг өөрөө арилна. Арилахгүй бол багцад
контент нэмэх эсвэл түр хаах шаардлагатай.

## ⚠️ 3. Docker лог хязгаар — daemon restart хүлээж байна

`/etc/docker/daemon.json`-д `50m × 3` тохиргоо **бичигдсэн** боловч
Docker daemon дахин ачаалагдтал үйлчлэхгүй.

```bash
# ⚠️ HLS хөрвүүлэлт ДУУССАНЫ ДАРАА хийнэ (ажил тасалдана)
ssh root@62.238.47.2 'systemctl reload docker'
```

`reload` нь `restart`-аас зөөлөн — ажиллаж буй container зогсохгүй.
Гэхдээ хөрвүүлэлт явж байхад эрсдэл авахгүй байх нь дээр.

## ℹ️ 4. `BLOCK_DEVTOOLS = false`

`frontend/src/components/content-protection.tsx:29`

Тайлбарт *«оношилгооны хугацаанд унтраалттай — бүх алдаа шийдэгдсэний
дараа `true` болгоно»* гэж бичсэн.

**Шийдэх зүйл:** `true` болгох уу?

Талууд:

- ✅ Санамсаргүй F12 дарахыг зогсооно
- ❌ **Бодит хамгаалалт өгөхгүй** — DevTools-ыг цэснээс нээх, эсвэл
  `view-source:` ашиглах боломжтой хэвээр
- ❌ Хөгжүүлэгч/дэмжлэгийн ажилтан алдаа шалгахад саад
- ❌ Зарим хэрэглэгч «вирус» гэж эргэлзэх

Видеоны бодит хамгаалалт нь **HLS + presigned URL + эрхийн шалгалт**
дээр тулгуурладаг (энэ нь ажиллаж байна). DevTools блок нь зөвхөн
харагдах саад.

**Зөвлөмж:** `false` хэвээр үлдээх. Хэрэв `true` болгохыг хүсвэл
тэр нэг мөрийг л өөрчилнө.
