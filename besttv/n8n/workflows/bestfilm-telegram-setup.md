## Танд хийх зүйл (5 минут)

### 1. Bot-ынхоо нэрийг олох

1. Telegram нээж, **BestTV-ийн мэдэгдэл ирдэг чат** руу орно
   (💰 Төлбөр орлоо гэх мэт мессеж ирдэг чат)
2. Дээд талын **нэр дээр дарна**
3. `@…bot` гэсэн нэрийг **хуулж авна** (жишээ: `@besttv_alert_bot`)

### 2. Шинэ групп үүсгэх

1. Telegram → зүүн дээд булан **☰** → **New Group**
2. **Contacts** жагсаалтаас 1-р алхамд олсон **bot-оо хайж сонгоно**

   ⚠️ Bot олдохгүй бол хайх талбарт `@` тэмдэгтэй бүтнээр нь бичнэ

3. **Next** → группийн нэр: **BestFilm мэдэгдэл**
4. **Create**

### 3. Bot-д эрх өгөх

⚠️ **Заавал** — эс бөгөөс мессеж илгээж чадахгүй.

1. Группийн **нэр дээр дарна**
2. **Edit** (харандаа) → **Administrators**
3. **Add Admin** → bot-оо сонгоно
4. **Send Messages** асаалттай эсэхийг шалгана
5. ✓ (баталгаажуулах)

### 4. Группийн ID олох — `@RawDataBot`

1. Группийн **нэр дээр дарна** → **Add Members**
2. `@RawDataBot` гэж хайж **нэмнэ**
3. Тэр bot орж ирмэгцээ мессеж бичнэ. Дотроос нь олно:

   ```
   "chat": {
     "id": -1001234567890      ← ЭНЭ тоог хуулна (хасах тэмдэгтэй нь)
     "title": "BestFilm мэдэгдэл"
   ```

4. Тоог хуулсны дараа `@RawDataBot`-ыг группээс **хасна**
   (нэр дээр дарах → Members → RawDataBot → Remove)

### 5. Надад хэлэх

```
BestFilm chat id: -1001234567890
```

Би 5 workflow-д тохируулж, туршиж өгнө.

```bash

```

Telegram node-ийн `chatId`-г илэрхийлэл болгоно:

```
={{ $('Webhook').first().json.body.site === 'bestfilm'
      ? '-1001234567890' : '1587161751' }}
```

⚠️ Шинэ node нэмэхгүй — нэг талбар л өөрчлөгдөнө. **BestTV-ийн
урсгал огт хөндөгдөхгүй**: `site` нь `bestfilm` биш бол (эсвэл
талбар байхгүй бол) хуучин чат руугаа очно.
