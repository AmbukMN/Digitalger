# Дэлгүүрт илгээх бэлтгэл

> ⚠️ Энэ жагсаалтыг **дараалан** гүйцэтгэнэ. Алгасвал review дээр
> татгалзана.

## 1. Бүртгэл (хамгийн эрт эхлүүлэх)

| Дэлгүүр | Үнэ | Хугацаа |
|---|---|---|
| **Apple Developer** | $99/жил | ⚠️ Байгууллагын бүртгэлд **D-U-N-S дугаар** 1–2 долоо хоног |
| **Google Play** | $25 нэг удаа | 1–2 өдөр |

⚠️ Apple-ийн бүртгэл хамгийн удаан — **одооноос эхлүүлэх** нь зүйтэй.

## 2. Тохиргоо (`.env.production`)

Эдгээргүй бол нэвтрэлт/төлбөр **аюулгүй хаагдана**:

```bash
# Apple Developer → Certificates, IDs & Profiles → Identifiers
APPLE_CLIENT_IDS=mn.besttv.app

# Google Cloud Console → APIs & Services → Credentials
# ⚠️ iOS болон Android ТУС ТУСДАА client ID үүсгэнэ
GOOGLE_MOBILE_CLIENT_IDS=<ios>.apps.googleusercontent.com,<android>.apps.googleusercontent.com

# Албадан шинэчлэлт — эвдэрсэн хувилбарыг зогсооно
APP_MIN_VERSION=1.0.0

# ⚠️ Apple татгалзвал `false` → төлбөрийн дэлгэц АЛСААС хаагдана
APP_PAYMENTS_ENABLED=true
```

## 3. EAS project

```bash
npm install -g eas-cli
eas login
eas init            # projectId үүснэ → app.json-д автоматаар бичигдэнэ
eas build:configure
```

⚠️ **`projectId` байхгүй бол push мэдэгдэл ОГТ ажиллахгүй** —
`getExpoPushTokenAsync` алдаа шидэж чимээгүй унана.

## 4. Build

```bash
eas build --platform ios --profile production
eas build --platform android --profile production
```

⚠️ Mac шаардлагагүй — EAS үүлэн дээр build хийнэ.

## 5. Дэлгүүрийн мэдээлэл

### Нэр / тайлбар

```
Нэр:      BestTV
Дэд нэр:  Монгол хадмалтай кино, цуврал

Тайлбар:
BestTV — монгол хадмалтай кино, олон ангит цувралыг гар утаснаасаа
үзэх боломж. Шинэ анги тутам мэдэгдэл авч, сүлжээгүй үед үзэхээр
урьдчилан татаж авна.

· 150+ кино, цуврал
· Сүлжээгүй үзэх (татаж авах)
· Үргэлжлүүлэн үзэх
· Дуртай жагсаалт
· 22 банкны аппаар шууд төлбөр
```

### Насны ангилал

⚠️⚠️ **12+** гэж мэдүүлнэ (`Infrequent/Mild Mature Themes`).

Апп нь 18+ контентыг **огт агуулдаггүй** — `/mobile/*` зам түүнийг
серверийн талд шүүдэг (batlagdsan: 154 кино, 18+ нь 0).

⛔ **Апп дотор 18+ рүү холбоос ТАВИХГҮЙ** — Apple Guideline 1.1.4-ийг
тойрох оролдлого гэж үзэж татгалзана.

### Дэлгэцийн зураг

⚠️ Apple: 6.7" (1290×2796) **заавал**, 6.5" нэмэлт
⚠️ Google: дор хаяж 2 ширхэг, 1080×1920

Санал болгох дараалал:
1. Нүүр (баннер + жанрын эгнээ)
2. Киноны дэлгэрэнгүй (ангийн жагсаалт)
3. Плеер (хэвтээ)
4. Татсан контент (офлайн)
5. Багц авах (банкны сонголт)

### Нууцлалын бодлого

⚠️ **ЗААВАЛ** — URL шаардана. Одоо байгаа хуудсыг ашиглана:
`https://besttv.us/p/privacy`

Дараах зүйлийг **тусгасан байх ёстой**:
- Цуглуулдаг өгөгдөл: имэйл, нэр, төлбөрийн түүх, үзсэн явц
- Push токен (мэдэгдэл илгээхэд)
- Төхөөрөмжийн мэдээлэл (session удирдлага)
- ⚠️ Apple-ийн **App Privacy** асуулгад ижил хариулт өгнө

### Дансны устгалт

⚠️⚠️ Apple **5.1.1(v)**: акаунт үүсгэдэг апп нь **устгах зам** өгөх ЁСТОЙ.

Одоо байгаа: `https://besttv.us/p/data-deletion`
⚠️ Апп дотроос ч хүрэх ёстой — Профайл → холбоос нэмэх шаардлагатай.

## 6. Туршилт

```bash

```

- [ ] Push мэдэгдэл ирж байгаа эсэх (симулятор дээр ажиллахгүй)
- [ ] Apple Sign-In
- [ ] QPay — банкны апп нээгдэж, буцаж ирэхэд эрх нээгдэх
- [ ] Офлайн татах → сүлжээ салгаад үзэх
- [ ] Плеер: дуудлага ирэхэд зогсох, PiP, дэлгэц эргэх
