shimmer Animation

Skeleton-д shimmer (гэрэл гялайх) animation нэмэх нь "амьд" мэдрэмж өгнө. Tailwind animate-pulse эсвэл custom shimmer animation.

Loading State Best Practices
✅ Шилдэг Дадлууд:
• Skeleton-г бодит layout-тайгаа яг ижил хэмжээнд хий — layout shift болохгүй
• 200ms-с бага хоцрогдолтой бол skeleton харуулахгүй байж болно — богино flash муу
• Error state: retry товчтой тодорхой мессэж ("Дахин оролдоно уу")
• Empty state: мэдээлэл байхгү…

Практик Алхамууд
  • ✓loading.tsx: app/products/loading.tsx үүсгэж, skeleton grid харуулна — Network throttling-р тест хий
  • ✓Skeleton component: ProductCardSkeleton-г бодит ProductCard-тайгаа хэмжээ тааруулж хий
  • ✓Error state: API call алдаатай бол retry button + тайлбар мессэж харуулна
  • ✓Chrome DevTools: Network → Slow 3G → products хуудас нээ → skeleton харагдахыг баталгаажуул
